# Network Administration Labs

### About this Repository

This repository documents hands-on exercises in network administration, including Cisco switch and router provisioning, VLAN traffic segmentation, and perimeter firewall management using pfSense and Suricata. These projects demonstrate practical skill in configuring, securing, and troubleshooting virtualized network infrastructure.

---

### Projects 

- [**Essential Switch Configuration:**](https://github.com/iagsalazar1-cs/Network-Administration-Labs/tree/main/01-Essential-Switch-Configuration) Configured basic network connectivity and security settings on a Cisco switch in Packet Tracer to establish baseline administrative access for a small LAN topology.

- [**Switch Port Security Configuration:**](https://www.google.com/search?q=https://github.com/iagsalazar1-cs/Network-Administration-Labs/tree/main/02-Switch-Port-Security-Configuration) Configured and tested port security policies on a Cisco switch in Packet Tracer, populating static MAC address tables and validating port violation actions.

- [**Initial Router Configuration:**](https://www.google.com/search?q=https://github.com/iagsalazar1-cs/Network-Administration-Labs/tree/main/03-Initial-Router-Configuration) Executed initial router setup in Packet Tracer, configuring management interfaces, assigning IPv4 addresses, and verifying fundamental Layer 3 reachability.

- [**Configuring Static Routes:**](https://www.google.com/search?q=https://github.com/iagsalazar1-cs/Network-Administration-Labs/tree/main/04-Configuring-Static-Routes) Configured static IPv4 routes across Cisco routers to establish multi-hop connectivity between three local subnets and an external network interface.

- [**Configuring VLANs and Trunks:**](https://www.google.com/search?q=https://github.com/iagsalazar1-cs/Network-Administration-Labs/tree/main/05-Configuring-VLANs-and-Trunks) Configured Virtual Local Area Networks (VLANs) and 802.1Q trunking links on Cisco switches to segment network traffic, isolate broadcast domains, and enhance access control.

- [**Implementing Access Control Lists:**](https://www.google.com/search?q=https://github.com/iagsalazar1-cs/Network-Administration-Labs/tree/main/06-Implementing-Access-Control-Lists) Configured standard and extended Access Control Lists (ACLs) on Cisco perimeter routers to filter network traffic based on source/destination IP addresses and protocols.

- [**Configuring Static, Dynamic, and Overload NAT:**](https://www.google.com/search?q=https://github.com/iagsalazar1-cs/Network-Administration-Labs/tree/main/07-Configuring-Static-Dynamic-Overload-NAT) Configured Static, Dynamic, and PAT/Overload Network Address Translation (NAT) on Cisco routers for private IP management and external internet access.

- [**PFSense Firewall Rule Configuration:**](https://www.google.com/search?q=https://github.com/iagsalazar1-cs/Network-Administration-Labs/tree/main/08-PFSense-Firewall-Rule-Configuration) Configured firewall pass/block rules via the pfSense web interface in a virtualized lab to regulate ICMP and web traffic flow.

- [**Suricata Installation and Rule Configuration on PFSense:**](https://www.google.com/search?q=https://github.com/iagsalazar1-cs/Network-Administration-Labs/tree/main/09-Suricata-Installation-and-Rule-Configuration-on-PFSense) Integrated the Suricata IDS/IPS package on a pfSense virtual firewall, configuring threat signature sets and evaluating alert logs during simulated scan activity.
